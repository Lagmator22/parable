# Why Parable uses Arkiv

An operator-hosted database would make the public register depend on the operator's API. On Rabdi, anyone can query the published writer and vault independently, inspect read-only graves, and extend retention where permissionless extension is enabled. Arkiv makes published records accessible to other apps and agents using the same indexed fields.

The writer wallet still controls what is first published. Parable compares the Arkiv count with the vault's own count and uses Sepolia transactions as independent evidence. The engine attempts to repair missing bot and death records.

World ID tokens and approval claims stay with the engine. Bot signing keys stay in server memory. The vault handles trading permissions, balances, prices and loss limits on Sepolia. Arkiv stores the public records needed to inspect the bot lifecycle.
